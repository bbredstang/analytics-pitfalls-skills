# Analytics Pitfalls & Principles: skills for your AI

Free skills for Claude, ChatGPT, Gemini and Microsoft 365 Copilot Cowork, made from the 79 pitfall and principle cards and the 10 frameworks by Brian Cariveau at [analyticspitfalls.com](https://www.analyticspitfalls.com/library).

A skill is a file your AI keeps, so it knows a card whenever your work runs into it.

## The data layers, bronze to gold

Everybody does bronze, silver and gold differently. Ask five teams what silver means and you’ll get five answers. Brian Cariveau’s four layers name each one for what’s in it, and the pattern holds in almost every business: call centers, websites, finance, marketing, claims, clinical. Almost no one does this. The teams that do catapult forward at fixing the foundation.

| Layer | Medallion | What it holds | Skill |
|---|---|---|---|
| Raw | (lands under bronze) | Exactly what the source system sent. Just dump it in, and never edit it. | [`analytics-pitfalls-data-layers`](skills/analytics-pitfalls-data-layers/SKILL.md) |
| Cleaned raw | Bronze | The same rows with the formats fixed, once: dates, time zones, money, numbers, codes, addresses. | [`analytics-pitfalls-bronze-cleaned-raw`](skills/analytics-pitfalls-bronze-cleaned-raw/SKILL.md) |
| System-specific | Silver | One system at a time, in its domain: one call system, one website, one claims system. | [`analytics-pitfalls-silver-system-specific`](skills/analytics-pitfalls-silver-system-specific/SKILL.md) |
| System-agnostic | Gold | Every system in a domain as one, with one definition, tied to the master data and certified at three stars. | [`analytics-pitfalls-gold-system-agnostic`](skills/analytics-pitfalls-gold-system-agnostic/SKILL.md) |

The data domains sit over the top. Every table is named in full words, with little to no abbreviations: stupidly simple for humans is stupidly simple for agents.

## How to use these skills

1. **Add the whole set, and the one for the moment you’re in.** The whole set knows every card. The moment skills go deeper, one question at a time.
2. **Bring the real thing.** Paste the draft, the request, the deck or the numbers. They work on your work, not on theory.
3. **Say what you’re doing.** Name the skill if you like, or just say what it is. The examples below work.
4. **Answer the questions.** It asks Brian Cariveau’s questions in order, skips the ones your work already answers, then names the one or two cards that matter most.
5. **For a strategy, expect a canvas and a board.** It puts the strategy on one page (People, Process, Technology, Agentic), then offers a board of skeptics to poke holes in it.
6. **Go in order.** The strategy, then each dashboard it calls for, then the readout. Each skill tells you what comes next.

Things to say once a skill is in:

- "We’re about to pilot an agent that answers customer emails. Poke holes in it.": Before the AI strategy (`analytics-pitfalls-before-the-ai-strategy`)
- "Here’s our data strategy draft. Run Before the data strategy on it.": Before the data strategy (`analytics-pitfalls-before-the-data-strategy`)
- "Here’s next year’s reporting roadmap. What would Brian ask?": Before the BI strategy (`analytics-pitfalls-before-the-bi-strategy`)
- "Here’s our lakehouse plan, bronze to gold. Does it hold up?": The data layers (`analytics-pitfalls-data-layers`)
- "Sales wants a new pipeline dashboard. Check it before we build anything.": Before the dashboard (`analytics-pitfalls-before-the-dashboard`)
- "Here’s the deck for Thursday’s readout. What’s it hiding?": Before the readout (`analytics-pitfalls-before-the-readout`)
- "Someone just told me the AI demo went great. Which card is that?": the whole set (`analytics-pitfalls`)

If you ask your AI how to use them, the whole set answers from these same steps.

## Add one

- **Claude** (a paid plan): Customize, Skills, +, Upload a skill. Pick the skill's .zip from [the skills page](https://www.analyticspitfalls.com/library/skills).
- **ChatGPT or Gemini**: where your plan has Skills, upload the same .zip.
- **Microsoft 365 Copilot Cowork**: Plugins, Add, Upload, and pick the skill's .skill file (the Cowork column below). Cowork wants SKILL.md at the top, which the .skill has.
- **Claude Code**: copy a folder from `skills/` into `~/.claude/skills/`.
- **An AI at work that won't take a skill**: open a card's `SKILL.md` and paste it in.

## In what order

The skills for a moment at work run in order, the way a spec comes before a plan before the build: the strategy, then the data, then the work, then the results. Each one says, when it finishes, which comes next. The cards and frameworks have no order: use them whenever one fits.

1. **The strategy**: `analytics-pitfalls-before-the-ai-strategy`, `analytics-pitfalls-before-the-data-strategy`, `analytics-pitfalls-before-the-bi-strategy`. Pick the one you’re writing. They sit side by side; there’s no order between them.
2. **The data**: `analytics-pitfalls-data-layers`, `analytics-pitfalls-bronze-cleaned-raw`, `analytics-pitfalls-silver-system-specific`, `analytics-pitfalls-gold-system-agnostic`. Start with the data layers, then bronze, silver and gold, in that order.
3. **The work**: `analytics-pitfalls-before-the-dashboard`. Once for each dashboard the strategy calls for.
4. **The results**: `analytics-pitfalls-before-the-readout`. When the first numbers go to leadership.
